## What follows from each

1. **Prefer established packages and older versions.** A new dependency is chosen from widely
   used packages, and pinned to a release at least 30 days old; where an older release passes
   the gates and the security audit, take it over the newest. The Python gate tools
   (`pytest-cov`, `hypothesis`, `complexipy`, `bandit`, `pip-audit`) and the `hatchling` build
   backend are accepted on that basis. Step 0C pins the build backend and lists the gate tools
   here.
2. **Pins are the target, not a guarantee.** `CLAUDE.md` said nothing is adapted per machine.
   That is now the aim, not a rule: where the work PC cannot install a pinned version, its
   copy uses the nearest version it can, and the difference is reported back so the pin here
   follows it. Vite stays at 6.4.5, unconfirmed on the work PC.
3. **Answer key for step 1A:** the predecessor's retained run
   `runs/cpos-tdg-sol-medium-all-001` (TransDigm, `case_kind` public, completed 2026-11-09),
   delivery `abd687ca74b49fbd703ed27dc3f8f9edaa20e12f0236efa80d9d1ea4757c2baa`: 20 module
   handoffs, 4,373 lines. It is the only complete run found on the development machine. It is
   not in the predecessor's repository (run folders are not committed there), so step 1A
   copies the 20 handoffs here as frozen fixtures and records each file's SHA-256.
   **Limit:** this run predates the reader-format ruling of 2026-11-11 and the 2026-11-13
   redesign, so it proves the grammar as it stood on 2026-11-09. The newer format is covered
   only by the predecessor's synthetic fixtures until a newer full run is retained; step 1A's
   plan says which grammar rules each fixture set proves.
4. **The cap is ported.** Step 3A carries `budget.py` and the Copilot rows of `pricing.py`. A
   launch whose hold exceeds the cap is refused, and the run start page (step 5C) submits
   under that cap.
5. **Model `gpt-6-sol`.** The predecessor's `copilot-sol-medium` configuration names
   `gpt-6.1-sol`; step 1C uses `gpt-6-sol` and does not copy that id.
6. **Browsers.** The open-from-disk check must pass in both Chrome and Edge. Step 0C adds an
   Edge run to CI on Windows.
7. **Run start stays a served page** (step 5C), bound to localhost.
